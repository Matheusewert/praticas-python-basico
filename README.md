# Práticas de Python Básico

## Objetivo
Reunir exercícios simples de Python feitos durante o curso de Python Básico da Fundação Bradesco.

## Conteúdo
- Condicionais (`if`)
- Laços (`for`)
- Funções (`def`)
- Listas

## Tecnologias
- Python 3

## Como executar
```bash
git clone https://github.com/Matheusewert/praticas-python-basico.git
cd praticas-python-basico
python praticas.py
```
